# Intro
This is a folder which holds my experiment on webcomponent based UI library

I believe framework / library should be simple enough ( not complicated enough ), 
so that anybody could recreate and maintain their own versions. 

All my efforts in this library are gonna go in the above direction. let's see how things goes

## goals
  creating a base html custom element that easies 
  - mounting ( element creation, event handling, css attachments, state tracking )
  - unmounting ( proper event, state cleanup and so )
  - state should be auto synced ( like signal - fine grained reactivity )
